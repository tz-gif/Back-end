# Java e JavaScript

## 📚 Sobre o Projeto

Este projeto foi desenvolvido durante as aulas de Desenvolvimento de Sistemas. O objetivo foi aprender e praticar os conceitos básicos das linguagens Java e JavaScript.

Durante as atividades, foram realizados exercícios para entender como cada linguagem funciona e como utilizar seus principais comandos.

---

## ☕ Java

Java é uma linguagem de programação utilizada para criar diferentes tipos de sistemas e aplicações.

Durante o aprendizado de Java, foram estudados conceitos como:

- Variáveis
- Tipos de dados
- Operadores
- Entrada de dados
- Condições
- `if` e `else`
- Estruturas de repetição
- `for` e `while`
- Métodos
- Classes e objetos

Os exercícios foram utilizados para praticar a lógica de programação e entender como criar programas utilizando Java.

---

## 🟨 JavaScript

JavaScript é uma linguagem muito utilizada no desenvolvimento de sites e aplicações web.

Ela permite criar páginas mais interativas e fazer com que os elementos do site respondam às ações do usuário.

Durante as atividades, foram estudados:

- Variáveis
- Tipos de dados
- Operadores
- Condições
- Funções
- Eventos
- Entrada de dados
- Manipulação de elementos HTML

---

## 🔎 Java x JavaScript

Apesar dos nomes serem parecidos, Java e JavaScript são linguagens diferentes.

**Java** é utilizado em vários tipos de aplicações e sistemas.

**JavaScript** é muito utilizado em páginas web para adicionar funcionalidades e interatividade.
